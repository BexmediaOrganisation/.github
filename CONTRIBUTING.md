# Contributing to Bexmedia repos

Thanks for helping. Every Bexmedia repo follows the same SOPs:

- **Changing code:** [Commits and pull requests](https://bexmediastudio.monday.com/docs/18438793528). Work on a branch, open a pull request into `main`, and give it a title like `fix: retry ffmpeg downloads`.
- **Releasing:** [Versioning and releases](https://bexmediastudio.monday.com/docs/18438794583).
- **Starting a repo:** [Starting a new repo](https://bexmediastudio.monday.com/docs/18439133662).

The SOPs live on Bexmedia's monday.com. If you can't open them, ask Tom.
