## Bexmedia standards

This repo follows the Bexmedia SOPs. Before making any change, read https://github.com/BexmediaOrganisation/.github/blob/main/CLAUDE.md and follow the SOP it points to.

When you write a pull request description, fill in its "What changes for the team" section: one plain-English line per change people using the app will notice, user-facing only, with no internals (no code, file or tool names). Leave it empty if nothing changes for them. The team is emailed these lines when the version is released, so a person must check them before merging.
